# FXAnalyzer — MT4 / MT5 Trade Analyzer

MetaTrader 4 / 5 の取引履歴をブラウザで読み込み、**EA名・マジックナンバー・シンボル別**に成績を分析するツールです。
HTMLファイル1枚で動作し、インストールは不要です。読み込んだデータが外部へ送信されることはありません。

複数のEAを異なるマジックナンバーで運用している人が、「どのEAが・どの通貨ペアで・どれだけ稼いでいるか」を把握するために作りました。

**すぐに使う:** https://teru-kuma.github.io/FXAnalyzer/
（読み込んだ取引履歴はブラウザの中だけで処理され、サーバーには送信されません）

## 主な機能

- **累積損益カーブ** — 0を境に緑（プラス）/ 赤（マイナス）で塗り分け
- **主要指標** — 純損益・最大ドローダウン・勝率・プロフィットファクター・取引数・平均損益
- **EA名 / マジック / シンボル別の集計** — 表の行をクリックすると1段ずつ掘り下げ（例: EA名 → シンボル → マジック）
- **EA組み合わせ分析** — 2〜3 EAを選び、各ペアの同時保有・同時損失・DD同時性から補完候補を確認
- **期間の切り替え** — 全期間 / 今週 / 今月 / 今年 / 期間指定、‹ › で前後の期間へ移動
- **金額 / pips の切り替え**
- **入出金と口座残高** — 開始残高・終了残高・リターン率、残高推移グラフ（入出金を含む履歴の場合）
- **複数口座の合算** — 複数ファイルをまとめて読み込み、口座（ソース）ごとの絞り込みも可能
- **CSV書き出し** — 集計表と取引一覧
- **スマホ表示対応** — 表は横スクロールで閲覧可能

## クイックスタート

1. https://teru-kuma.github.io/FXAnalyzer/ を開く（またはダウンロードした `MT_Trade_Analyzer.html` をブラウザで開く）
2. 「ファイルを読み込む」から取引履歴を選ぶ（PCでは画面へのドラッグ&ドロップも可）
3. 集計・グラフが表示される

## 読み込めるファイル

| 形式 | 入手方法 | マジックナンバー |
|---|---|---|
| **TSV（推奨）** | 同梱の `ExportHistoryTSV` スクリプトで書き出す | **端末から直接取得するので正確** |
| MT4 HTMLレポート | 口座履歴タブ → 右クリック →「詳細レポートの保存」 | コメント欄から推定 |
| MT5 HTMLレポート | 履歴タブ → 右クリック →「レポート」→ HTML | コメント欄から推定 |

> **HTMLレポートにはマジックナンバーの列がありません。**
> そのためコメント欄から推定しますが、コメントにレート（145.612 など）を書き込むEAでは誤判定が起きます。
> 正確な集計には TSV を使ってください。

## 取引履歴の書き出しスクリプト（ExportHistoryTSV）

MT4版（`.mq4` / `.ex4`）と MT5版（`.mq5` / `.ex5`）を同梱しています。コンパイル済みの `.ex4` / `.ex5` はそのまま使えます。

### 使い方

1. MT4/MT5 のメニュー「ファイル → データフォルダを開く」
2. `MQL4/Scripts/`（MT5は `MQL5/Scripts/`）に `ExportHistoryTSV.ex4`（または `.ex5`）を置く
3. ナビゲータの「スクリプト」を右クリック →「更新」
4. `ExportHistoryTSV` を任意のチャートへドラッグし、パラメータを設定して実行
5. `MQL4/Files/`（MT5は `MQL5/Files/`）に `history_<口座番号>_<日付>.tsv` が作られる
6. そのTSVを `MT_Trade_Analyzer.html` で読み込む

> **MT4の注意:** MT4は「口座履歴」タブに表示されている範囲しか取得できません。
> 実行前に口座履歴タブを右クリック →「全履歴」を選んでおいてください。

### パラメータ

| 名前 | 既定値 | 内容 |
|---|---|---|
| `InpFileName` | 空欄 | 出力ファイル名。空欄なら `history_<口座番号>_<日付>.tsv` |
| `InpSubFolder` | 空欄 | 出力先サブフォルダ。空欄なら `Files` 直下 |
| `InpFrom` / `InpTo` | 0 | この決済日時の範囲だけ出力（0 = 全期間） |
| `InpIncludeBalance` | false | **入出金も出力する。残高・リターン率を見たい場合は true** |
| `InpIncludeOpen` | false | 未決済ポジションも出力する |

### Google Drive に自動で上げる

MQL のファイル操作は `Files` フォルダの外に書き込めないため、スクリプトから直接 Google Drive へは保存できません。
代わりに次の方法を使います。

1. `InpSubFolder` に `export` などを指定して書き出す
2. Google Drive デスクトップ版の設定 →「パソコン」→ フォルダを追加 → `MQL5/Files/export` を指定

以後、書き出したTSVが自動で Drive に同期され、スマホの Drive アプリからも開けます。

## 画面の見かた

### 絞り込み（PCでは左側、スマホでは上部）

- **期間** — 「今週」「今月」「今年」はデータの最終日を基準にします（過去の履歴を読んでも空にならないため）
- **表示** — 金額 / pips の切り替え、未決済を含めるか、分割決済をまとめるか
- **EA名 / マジック / シンボル** — チェックで絞り込み。操作したリストがそのまま集計の軸になります
- **ソース** — 複数口座を読み込んだときの口座の絞り込み（集計の軸とは別に常に効きます）

### タブ

| タブ | 内容 |
|---|---|
| 集計 | 軸ごとの成績。行をクリックで掘り下げ、上部のパンくずで戻る |
| 取引一覧 | 全取引。列見出しで並び替え、ページ送り |
| 比較 | チェックした2〜3件のEAをペアごとに確認し、補完候補・確認候補・慎重候補の案内を見る |
| 入出金 | 入出金の一覧とその時点の残高（入出金を含む履歴の場合のみ表示） |
| EA名の対応表 | マジックごとにEA名を手動で指定。指定はブラウザに保存され、JSONで書き出し・読み込みも可能 |
| 診断 | 読み込み結果の詳細。うまく読めないときは、この内容を共有すると原因を特定しやすくなります |

### 選んだEA同士を比較する

1. EA分析の表で、見比べたい2 EA（必要なら3 EA）に「比較」をチェックする
2. グラフ上部の切り替えで「EA名別」を選ぶと、選んだEAのカーブが重なって表示される
3. 「比較」タブで、EAペアごとの見立てと、その根拠の数値を確認する

このとき上部の指標（純損益・最大DD・PF など）は、選んだEAを**一緒に運用した場合の合計**になります。
集計の軸はドリルダウンと連動するので、EAに掘り下げてからシンボルを選べば、そのEAのシンボル同士の比較になります。

- **補完候補・確認候補・慎重候補** は総合スコアではありません。同時保有・同時損失日・DD同時性を別々に、明示的な閾値で案内します。
- **同時保有** は、あるEAが保有していた時間のうち、もう一方も保有していた割合です。Entry / Exit日時がある取引だけを使います。
- **同時損失日** は、あるEAの損失日のうち、もう一方も損失だった割合です。取引がない日は損失に数えません。
- **DDの同時性** は、生のDD重複率から相手EAの通常のDD滞在率を差し引きます。長期DDのEA同士で数値が高止まりする影響を抑えます。
- 根拠の数値を開くと、方向別の比率、比較期間、取引数を確認できます。
- 取引数30件未満または比較期間90日未満では、注意を表示します。分析自体は行います。

### リターン率の定義

```
リターン率 = 純損益 ÷（期間開始時の残高 ＋ 期間中の入金）
```

期間中に投じた資金に対する損益の割合です。口座開設時から見ている場合（開始残高 0）でも計算できます。

### 損益の基準

主要指標の「純損益」、PF、DD、平均損益、リターン率は、**Profit + 手数料 + スワップ + fee 等**を反映した実質損益（`net`）で計算します。
取引一覧とCSVには、比較用にコスト前の `profit`、コスト、実質損益を分けて表示します。

## 動作環境・注意事項

- **グラフ描画に Chart.js を CDN から読み込みます。** オフラインでは簡易的な描画に切り替わります
- `file://` で開いた場合、ブラウザによっては保存機能（localStorage）が使えません。その場合、EA名の手動指定は「JSONで書き出し」で保存してください
- **口座通貨が異なる複数口座を合算すると、金額の合計には意味がありません。** 表示単位を pips にするか、ソースで1つに絞ってください
- 口座残高は「それまでの入出金 ＋ 確定損益」で計算します。口座開設時からの全履歴を読み込んだ場合に実際の残高と一致します
- スマホ単体では取引履歴を書き出せません（MT4/MT5 のモバイル版はスクリプトを実行できないため）。PCで書き出したファイルを Google Drive などで持ち込んでください
- **スマホでは上記の公開URLから使ってください。** iPhone の「ファイル」アプリで HTML を直接開くとプレビュー表示になり、ツールとして動きません。公開URLをホーム画面に追加すると、アプリのように使えます
